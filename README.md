# PlateMate

PlateMate is a native Android application built with Kotlin and Jetpack Compose. It focuses on community-based vehicle plate search, driver reputation signals, plate reviews, discovery trends, saved plates, authentication, and messaging infrastructure.

## Tech Stack

- Kotlin
- Jetpack Compose and Material 3
- Clean Architecture and MVVM
- Hilt dependency injection
- Retrofit, OkHttp, and Gson
- Room and DataStore
- Kotlin Coroutines and Flow
- Socket.IO
- Firebase Analytics
- JUnit, MockWebServer, Compose UI tests, and Macrobenchmark scaffolding

## Setup

This repository does not include `app/google-services.json`. Add your own Firebase config file under `app/` before building variants that use Google Services.
